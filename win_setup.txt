================================================================================
COLLEGE LEAVE MANAGEMENT SYSTEM (CLMS) - WINDOWS 10 SETUP GUIDE
================================================================================

This guide walks you through moving the CLMS project from your current machine
to a fresh Windows 10 PC and running it exactly as it works now (frontend,
backend, and MongoDB via Docker).

--------------------------------------------------------------------------------
1. PREREQUISITES ON WINDOWS 10
--------------------------------------------------------------------------------

Install the following (all have official Windows installers):

  Tool                  Purpose                           Where to get
  --------------------- --------------------------------- ---------------------
  Node.js LTS (v20+)    Runtime for backend + frontend    https://nodejs.org
                        (download the Windows Installer .msi, "LTS" version)
  Docker Desktop        Runs the MongoDB container        https://www.docker.com
                        for Windows
  Git (optional)        To clone/copy the repo            https://git-scm.com

After installing Node.js, open a new PowerShell or Command Prompt and verify:

  node -v
  npm -v

If Docker Desktop prompts you, enable WSL 2 (required for Docker on Windows 10
Home/Pro).

--------------------------------------------------------------------------------
2. EXPORT THE FILES TO THE WINDOWS PC
--------------------------------------------------------------------------------

Option A - Copy the whole folder (recommended):
  Copy the entire Leave-Letter-Management folder to the Windows PC via USB,
  network share, or cloud drive. Place it at:

    C:\Users\<YourName>\Documents\Leave-Letter-Management

Option B - Git clone (if the repo is on a remote):
  Open PowerShell on the Windows PC and run:

    git clone <repository-url>
    cd Leave-Letter-Management

--------------------------------------------------------------------------------
3. BACKEND SETUP (backend/)
--------------------------------------------------------------------------------

Open PowerShell in the backend folder:

    cd C:\Users\<YourName>\Documents\Leave-Letter-Management\backend

Install dependencies:

    npm install

Create the .env file:

    notepad .env

Paste the following content into backend\.env:

  PORT=5000
  NODE_ENV=development
  MONGODB_URI=mongodb://localhost:27017/clms
  CLIENT_URL=http://localhost:5173
  JWT_ACCESS_SECRET=replace_with_a_long_random_secret_at_least_32_chars
  JWT_REFRESH_SECRET=replace_with_another_long_random_secret_must_differ
  ADMIN_NAME=Initial Administrator
  ADMIN_EMAIL=admin@example.com
  ADMIN_PASSWORD=DemoOnly!Admin123

Important rules for the JWT secrets:
  - Each secret must be at least 32 characters long.
  - JWT_ACCESS_SECRET and JWT_REFRESH_SECRET must NOT be identical.

Generate strong secrets with:

  node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"

--------------------------------------------------------------------------------
4. FRONTEND SETUP (frontend/)
--------------------------------------------------------------------------------

Open a new PowerShell window in the frontend folder:

    cd C:\Users\<YourName>\Documents\Leave-Letter-Management\frontend
    npm install

The frontend already proxies /api and /socket.io to http://localhost:5000 via
vite.config.js, so no changes are normally needed unless you change ports.

--------------------------------------------------------------------------------
5. START MONGODB WITH DOCKER
--------------------------------------------------------------------------------

Make sure Docker Desktop is running (check the whale icon in the system tray).

Open PowerShell and run:

    docker run -d --name clms-mongo -p 27017:27017 -v clms_mongo_data:/data/db mongo:7

Verify it is running:

    docker ps

You should see clms-mongo listed.

If the container already exists and is stopped, start it instead:

    docker start clms-mongo

--------------------------------------------------------------------------------
6. SEED THE DATABASE
--------------------------------------------------------------------------------

Still in the backend folder, run the seed scripts in order:

    npm run seed:admin
    npm run seed:departments
    npm run seed:phase4

These create:
  - The admin bootstrap account
  - Five departments: CSE, IT, ECE, MECH, MCA
  - Demo classes, tutors, students, parents, and parent-child links

--------------------------------------------------------------------------------
7. RUN THE PROJECT (TWO TERMINALS)
--------------------------------------------------------------------------------

Terminal 1 - Backend:

    cd C:\Users\<YourName>\Documents\Leave-Letter-Management\backend
    npm run dev

It should connect to MongoDB and listen on http://localhost:5000.

Terminal 2 - Frontend:

    cd C:\Users\<YourName>\Documents\Leave-Letter-Management\frontend
    npm run dev

Vite will start on http://localhost:5173.

Open your browser and go to:

    http://localhost:5173

--------------------------------------------------------------------------------
9. USEFUL WINDOWS COMMANDS
--------------------------------------------------------------------------------

Stop MongoDB container:
    docker stop clms-mongo

Remove container (fresh start):
    docker rm clms-mongo

Run frontend lint:
    cd frontend
    npm run lint

Build frontend for production:
    cd frontend
    npm run build

Check backend health:
    http://localhost:5000/health

--------------------------------------------------------------------------------
10. COMMON WINDOWS ISSUES & FIXES
--------------------------------------------------------------------------------

  Issue                                 Fix
  -----                                 ---
  'docker' is not recognized            Docker Desktop isn't running or not
                                        installed. Start it from the Start Menu.
  MongoDB connection failed             Make sure clms-mongo is running
                                        (docker ps) and port 27017 is free.
  JWT secret must be 32+ characters     Lengthen the secrets in backend/.env.
  EACCES / permission errors on npm     Run PowerShell as Administrator, or
  install                               delete node_modules and package-lock.json
                                        then run npm install again.
  Frontend can't reach backend          Verify http://localhost:5000/health
                                        loads in the browser; check Windows
                                        Defender firewall isn't blocking Node.
